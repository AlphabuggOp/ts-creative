# sanctum — the app

The whole experience is a static site: no accounts, no servers, no environment variables.
Progress persists in an on-device save; the cover layer and the Sanctum are one toggleable reality.

## Run it

```bash
npm ci          # Node 20.19+
npm run dev     # local dev on http://localhost:5173
npm run build   # type-check + production bundle → dist/
npm run preview # serve the production bundle locally
```

## Inside

- **The Cover** — an abandoned shortwave blog ("SIGNAL & STATIC") that is its own complete website.
  The unlock ritual is taught by the fiction itself.
- **The Gate** — a scroll-driven transmission with whisper motes.
- **The Trials** — an inertia orbit of three rites: five signal rounds + an endless master band,
  five focus waves (one lies to you), three dilemmas whose verdicts become six playable proofs.
- **The Ceremony** — forges rank, callsign and a generative sigil from your play.
- **The Departure** — the way back out, through the ring.
- **The Field Log** — `Esc` or the burger chip: identity, tasks, nineteen quests, the archive.

## Keys

`~` panic to the surface · `Esc` Field Log · `1–5` log tabs · `↑ ↑ ↓ ↓` hurry the Seal ·
`Ctrl+Alt+D` forget everything · wheel/drag to move through everything that moves.

Deploys straight to any static host (Vercel/Netlify configs included).
