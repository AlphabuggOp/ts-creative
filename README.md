# PROJECT SANCTUM

**The network that pretends not to exist.** — Team CCA · TS '26 Creative

A secret-network experience hidden behind an abandoned shortwave blog. Find the door,
pass three rites — _Signal, Focus, Choice_ — and the network mints your rank, callsign
and sigil from how you actually played. Press `~` at any moment and it vanishes.

🌐 **Live:** [ts-creative.vercel.app](https://ts-creative.vercel.app)

- `sanctum/` — the app (Vite + React + TypeScript, fully static)
- `deliverables/` — the write-up, the UI/UX design dossier, and the access briefing
